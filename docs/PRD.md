개인 포트폴리오 사이트 PRD
개요
박주혜의 디자인 프로젝트를 하나의 링크로 소개하고, 새 작업이 생길 때마다 같은 구조에 추가할 수 있는 Next.js 기반 포트폴리오를 만든다. 첫 공개 규모는 약 3~4개 프로젝트다. 방문자는 메인에서 작업을 고르고, 상세에서 기여한 역할과 결과물을 확인한 뒤 하단 Contact로 연락한다.

규칙
분류 — 필터 순서는 ALL → Branding → Graphic → Editorial → Typography → 3D → Motion이다. ALL은 전체 보기다. 미분류 작업도 ALL에 포함하며, 등록 수가 0개인 분류도 필터에 남긴다.
목록과 상세 — 목록에는 표시 연도만 쓰고 상세에는 입력한 전체 기간을 쓴다. 선택 정보가 비어 있으면 해당 라벨과 자리를 함께 생략한다. 영상이 없는 작업에 빈 플레이어를 두지 않는다.
레이아웃 — PC는 4열, 모바일은 2열이다. 초과한 항목은 다음 줄로 보낸다. 상세에서는 주요 작업물 한 점이 콘텐츠 폭을 넓게 쓰도록 하고 원본 비율을 유지한다. PC에서 썸네일과 상세 이미지가 의도치 않게 잘리거나 겹치지 않아야 한다.
시각·언어 — 작업물의 색과 그래픽을 중심에 두고 카드 장식과 그림자는 최소화한다. 메뉴·분류·정보 라벨과 주요 프로젝트 표기는 영어가 기본이다. 제목과 설명에는 한국어를 함께 쓸 수 있고, 문장별 대역은 선택 사항이다.
Contact — 두 화면의 하단에 둔다. 이름과 직무 표기는 박주혜 Juhye, Designer다. 제공 자료의 연락처 표기는 -@gmail.com, Instagram @-이며, 공개용 실제 연결값은 남은 질문에서 확인한다.
영상 — 방문자가 재생을 선택하면 시작한다. 직접 재생이 어려운 영상은 운영자가 공개 전에 YouTube 대체본을 지정해 같은 위치에 삽입한다.

만드는 방법
콘텐츠 구조를 먼저 만든다. 프로젝트별로 제목과 고유 주소를 연결하고 나머지 정보와 작업물 목록은 선택 입력으로 둔다. 분류 목록과 공통 프로필은 한 곳에서 관리한다.
Next.js에 두 화면을 연결한다. /는 전체 또는 선택 분류의 프로젝트를 그린다. /projects/[slug]는 주소에 해당하는 데이터 한 건을 공통 상세 양식에 넣는다. 브라우저 탭에 각 화면의 기본 페이지 제목을 설정한다.
미디어를 실제 표시 크기로 점검한다. 화면설계의 권장 방식은 편집 원본을 별도 보관하고, 웹용 썸네일과 상세 이미지를 프로젝트별 폴더로 관리하는 것이다. 첫 작업을 PC에 표시해 작은 글자와 그래픽의 선명도를 확인한 뒤 압축 기준을 정한다. 직접 재생 영상은 웹용 MP4가 권장안이다.
공통 Contact를 연결한다. 이메일의 표시값과 mailto: 수신인을 일치시키고 Instagram 계정을 해당 프로필 주소에 연결한다. 두 화면 하단에서 같은 정보를 사용한다.
콘텐츠와 경계 사례를 검수하고 배포한다. 첫 공개 작업으로 목록·상세·연락 흐름을 확인한다. 제목만 있는 작업, 영상 없는 작업, 빈 분류, 전체 0건도 표의 수용 기준으로 검수한다. 4열·2열 줄바꿈은 임시 항목 5개로 확인한다. 배포 후 외부 브라우저에서 기본 주소와 상세 주소를 각각 연다.
화면설계의 기술 권장안은 Next.js App Router + TypeScript, 초기 배포 권장안은 Vercel 기본 주소다. Next.js 사용과 외부 공유 링크 제공은 확정이며, 권장안의 채택 여부는 아래에 남긴다.
